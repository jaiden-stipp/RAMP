# Project-wide research budgets

`node src/cli.js budgets <ramp.json>` shows consumed, reserved, and remaining source/iteration allowances and the reservations/outcomes that caused them. The local `.ramp/budgets.jsonl` ledger is bound to the project ID and limits; changing agents/modules never resets it. A changed limit requires an explicit migration design rather than silently rewriting historical counters.

The `BudgetStore` API reserves a `sources` or `iterations` slot, records `begin` immediately before execution, then `finish` with succeeded/failed/cancelled. Cancellation before begin releases the slot; cancellation or failure after begin consumes it. A crash leaves the reservation held until the operator determines whether execution began; no automatic expiry can permit double spending. Actors must be configured agent IDs (or operator). Reservation ownership cannot be transferred by another agent.

One unique source is one canonical source key across the whole project. HTTP(S) keys normalize scheme/host/default port through URL and omit fragments, preserving path/query semantics. Keys may also be explicit project-relative source identifiers; backslashes normalize to slashes. Mirrors and derivative publications need operator source review; the counter cannot infer intellectual independence. A first attempt consumes a source even if retrieval fails. A repeated committed key costs zero extra slots; an in-flight duplicate is rejected. Reviews of already recorded sources can continue at the source ceiling. Credential-bearing URLs are refused.

One iteration is an explicitly identified research cycle, including the initial cycle and each new gather/analyze cycle after review rework. Every begun cycle counts once even if it fails or is cancelled. A cycle ID cannot be spent twice. Finish the currently authorized cycle within its remaining source allowance; reserve another iteration before starting rework. Review, handoff, and partial delivery that use existing evidence do not themselves consume an iteration or source.

`--event <event.json>` accepts ledger events (type reserve/begin/finish/cancel; token; kind/key on reserve; agent; reason; outcome on finish). API users should prefer `reserve/begin/finish/cancel` methods, which create tokens and bind project/limits. Local directory mutex, chain validation, and fsync serialize reservation decisions; another writer may get a busy error and retry. Tests launch four processes against one remaining slot. This is local-filesystem concurrency, not a distributed quota service. Do not delete the ledger to restart budgets.

When a budget ledger exists, new handoff checkpoints use its consumed+reserved counts rather than caller-supplied counters. Old manual checkpoints remain historical snapshots; resume does not restore or overwrite budget counters. Before importing prior manual research into mediated operation, explicitly account for its source/cycle history. Only mediated calls can be enforced. The ledger cannot prevent tools used outside the host boundary and does not establish source truth.
