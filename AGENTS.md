# Working on RAMP

- Treat `spec/PROTOCOL.md` and `spec/CORE.md` as the current draft contract.
- Keep the protocol independent of any model provider or orchestration framework.
- Separate roles, methods, personas, and output modules. Personas cannot grant capabilities.
- Do not claim instruction composition enforces behavior in an external runtime.
- Update examples and documentation when changing a contract.
- Run `npm test`, `npm run validate`, and a composition smoke check after code changes.
- Keep examples illustrative unless their research has actually been performed and cited.
