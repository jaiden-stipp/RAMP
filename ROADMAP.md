# Roadmap

## Available in 0.1.0

- Draft core protocol, research lifecycle, evidence and handoff contracts.
- Composable role, method, persona, and output modules.
- Project validator and Markdown instruction composer without external packages.
- Example project, reusable templates, and composition tests.

## Next: validate the idea

- Run a real research project and record where instructions or handoffs fail.
- Compare one agent changing roles with multiple independent agents.
- Turn observed failures into protocol changes and conformance fixtures.
- Decide on a distribution license and governance before an open release.

## Proposed extensions

- Available: JSON Schemas, editor support, and machine-readable diagnostics for manifests and modules. Research artifact schemas follow in the persistence work.
- Task and evidence validators, state transitions, and budget accounting.
- Host adapters that enforce capabilities and phase gates.
- Module version resolution, lockfiles, and a reviewed module registry.
- Evaluation of citation accuracy, preserved uncertainty, and handoff quality.
- Optional orchestration and an interface for assembling agent configurations.

These extensions are proposals, not implemented features. Prioritize evidence from the first real project before expanding the runtime.
