# Source strategy and acceptance plan

Use exactly the three identified primary documents. The JSON Schema publication establishes its declared validation scope; the PROV overview and data model establish their provenance concepts. The two PROV documents are related, not independent replication. Inspect precise sections, retain publication-status limitations, and challenge the initial universal hypothesis.

Record one single-context condition with self-review and one separately authorized analyst context using the same source packet. A different reviewer context will assess both outputs after they exist; that is separate model review, not human review. Shared sources, lack of blinding/randomization, and unknown exact model version prevent a general causal performance conclusion.

Acceptance criteria: cite the three examined sources; correct unsupported universal wording; retain implementation dependence, related-source dependence, and non-benchmark limitations; preserve unresolved questions in a handoff; report what was and was not measured. The offline harness must reproduce structural counts and negative controls without live model calls.
